# Donut POS

A frontend-only POS prototype for a donut shop created through collaboration between UI/UX design and frontend development.

## Purpose
This project focuses on transforming UI/UX concepts into a functional interactive cashier experience.

## Scope
- Frontend only
- No backend integration
- Local state management
- POS workflow simulation

## Features
- Product categories
- Add/remove cart items
- Quantity controls
- Order summary
- Payment UI flow
- Persistent local storage
